# OpenWEZ

Browser-based precision ballistics calculator with Monte Carlo Weapon
Employment Zone analysis: trajectory tables, load comparison, and hit
probability on rectangle, circle, IPSC and animal-silhouette targets, with an
analytic error budget shown beside the Monte Carlo result.

**Use it:** https://reevesjustin.github.io/OpenWEZ/

The application runs entirely in the browser; the solver is compiled to
WebAssembly. This repository hosts the built site (branch `gh-pages`).
Development happens in a private repository.

accuracy of any calculation. Validate against established ballistic software
